# 🎮 Tic-Tac-Toe in Java

A simple console-based Tic-Tac-Toe game built using **Java** and basic **OOP concepts**.

### Features

* Two-player gameplay
* Win and draw detection
* Input validation
* Console-based interface

### Run

```bash
javac Main.java
java Main
```

Built for learning and practicing Java programming.
